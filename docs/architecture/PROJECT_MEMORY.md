## 2. Monorepo Directory & Architectural Responsibilities

### `ai-engine/` (Python 3.11+, Clean Architecture)
- **`app/domain/`**:
  - **Core responsibility**: Business entities, value objects, domain rules (`beneish.py`, `hard_laws.py`, `scoring.py`, `thesis_engine.py`, `counter_thesis.py`), 12 autonomous agents, and repository contracts.
  - **Rule**: Zero imports of database ORMs (SQLAlchemy), HTTP frameworks (FastAPI), or external SDKs.
- **`app/application/`**:
  - **Core responsibility**: Use-case orchestration, pipelines (`daily_pipeline_orchestrator.py`, `daily_etl.py`), multi-agent coordination.
  - **Rule**: Coordinates domain interfaces with infrastructure services without exposing HTTP transport concerns.
- **`app/infrastructure/`**:
  - **Core responsibility**: Concrete PostgreSQL pools/repositories, Redis cache, DNSE market feeds, R2 storage adapter (`r2_storage.py`), external APIs.
  - **Rule**: Implements domain interfaces; contains all I/O details.
- **`app/presentation/`**:
  - **Core responsibility**: FastAPI routers, request/response DTOs, endpoint controllers.
  - **Rule**: Thin layer. Parses incoming requests, delegates to application services, serializes responses.
- **`app/core/`**:
  - **Core responsibility**: Application settings (`config/settings.py`), structured logging, security tokens, UTC/ICT time utilities (`time_utils.py`).
- **`app/backtest/` & `app/eval/`**:
  - **Core responsibility**: Walk-forward backtesting, Sharpe/Sortino/Drawdown evaluations, audit trail hash chaining (`audit_trail.py`).
